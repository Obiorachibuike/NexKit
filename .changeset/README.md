# Changesets

This folder is used by [Changesets](https://github.com/changesets/changesets) to track
version bumps. Run `npm run changeset` after a user-facing change and commit the generated
markdown file with your PR. See `docs/PUBLISHING.md` for the full release flow.

All `@nexkitjs/*` packages are versioned together ("fixed" group) so a single version number
describes a compatible set.
