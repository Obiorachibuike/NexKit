# @nexkitjs/cli

The `nexkit` command-line tool: scaffold configuration and middleware, and diagnose your setup.

```bash
npx @nexkitjs/cli init --framework express
# or install it
npm install -D @nexkitjs/cli && npx nexkit --help
```

## Commands

| Command                                                                                  | Description                                                                                                                                 |
| ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `nexkit init [--framework express\|fastify\|none] [--dir src]`                           | Creates `src/config/env.ts`, `src/nexkit.ts` (framework wiring) and `.env.example`; prints the install command                              |
| `nexkit doctor`                                                                          | Checks Node version, `"type": "module"`, `moduleResolution`, installed `@nexkitjs/*` versions, peer deps, `.env` git-ignore, `.env.example` |
| `nexkit generate config [--out path] [--from .env.example] [--example]`                  | Generates a typed env schema; infers variables and types from an existing `.env`/`.env.example`                                             |
| `nexkit generate middleware [--framework …] [--out path] [--no-health] [--no-ratelimit]` | Generates framework wiring                                                                                                                  |

Global flags: `--force` (overwrite), `--dry-run`, `--help`, `--version`.

Generated files are plain TypeScript you own — edit them freely. Every template variant is
type-checked in the test-suite, and the repository's example apps are generated by this CLI.

## Programmatic use

```ts
import { run, renderEnvConfig, inferEnvFields } from "@nexkitjs/cli";
const code = await run(["generate", "config", "--dry-run"], {
  cwd,
  stdout: console.log,
  stderr: console.error,
});
```
