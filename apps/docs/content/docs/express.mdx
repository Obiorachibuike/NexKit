# Express

`@nexkitjs/express` provides middleware for Express **4.18+ and 5.x**. Each piece is
independent; use the ones you need in the order shown.

```bash
npm install @nexkitjs/express @nexkitjs/logger @nexkitjs/health @nexkitjs/ratelimit express
```

<Callout type="note" title="Express 4 vs 5">
  Express 5 forwards rejected promises from async handlers to the error handler
  automatically. On Express 4 wrap async handlers with `asyncHandler()` (exported by this
  package) or use `express-async-errors`.
</Callout>

## Complete example

```ts title="src/app.ts"
import express from "express";
import { z } from "zod";
import { createLogger } from "@nexkitjs/logger";
import { createHealthRegistry } from "@nexkitjs/health";
import { createFixedWindowLimiter, createRedisStore } from "@nexkitjs/ratelimit";
import { NotFoundError } from "@nexkitjs/errors";
import { ok, created, paginated, parsePagination } from "@nexkitjs/response";
import {
  requestContext, secureHeaders, requestSizeLimit, healthRoutes, rateLimit,
  validateRequest, getValidated, notFoundHandler, errorHandler,
} from "@nexkitjs/express";
import { env } from "./config/env.js";

const logger = createLogger({ name: "api", level: env.LOG_LEVEL });
const health = createHealthRegistry();
health.register("postgres", (signal) => db.ping({ signal }), { timeoutMs: 2000 });

const limiter = createFixedWindowLimiter({ store: createRedisStore(redis), limit: 100, windowMs: 60_000 });

export const app = express();
app.set("trust proxy", 1);

// 1. infrastructure
app.use(requestContext({ logger, ignore: ["/health/live", "/health/ready"] }));
app.use(secureHeaders({ strictTransportSecurity: env.NODE_ENV === "production" ? {} : false }));
app.use(requestSizeLimit({ maxBytes: "1mb" }));
app.use(express.json({ limit: "1mb" }));
app.use(healthRoutes(health));
app.use("/api", rateLimit({ limiter, keyGenerator: (req) => req.ip ?? "unknown" }));

// 2. routes
const CreateUser = z.object({ name: z.string().min(2), email: z.string().email() });
const UserParams = z.object({ id: z.coerce.number().int().positive() });

app.get("/api/users", async (req, res) => {
  const { page, pageSize, offset, limit } = parsePagination(req.query, { maxPageSize: 50 });
  const [rows, total] = await Promise.all([users.list({ offset, limit }), users.count()]);
  res.json(paginated(rows, { page, pageSize, total }, { requestId: req.id }));
});

app.get("/api/users/:id", validateRequest({ params: UserParams }), async (req, res) => {
  const { params } = getValidated<unknown, unknown, z.infer<typeof UserParams>>(req);
  const user = await users.find(params.id);
  if (!user) throw new NotFoundError(`User ${params.id} not found`);
  res.json(ok(user, { requestId: req.id }));
});

app.post("/api/users", validateRequest({ body: CreateUser }), async (req, res) => {
  const { body } = getValidated<z.infer<typeof CreateUser>>(req);
  const user = await users.create(body);
  res.status(201).json(created(user, { requestId: req.id }));
});

// 3. terminal handlers
app.use(notFoundHandler());
app.use(errorHandler({ logger }));
```

```ts title="src/server.ts"
import { app } from "./app.js";
import { env } from "./config/env.js";

const server = app.listen(env.PORT);
process.on("SIGTERM", () => server.close(() => process.exit(0)));
```

The repository contains this app, with tests, in
[`examples/express-app`](https://github.com/Obiorachibuike/NexKit/tree/main/examples/express-app).

## Middleware reference

### `requestContext(options)`

Assigns/validates request and correlation ids, sets `req.id` and `req.correlationId`,
echoes the headers, runs the rest of the chain inside the NexKit request context and logs
one entry per completed request. Options are documented in
[Request utilities](/docs/request-utilities/#configuration). Mount it **first**.

### `secureHeaders(options)`

Applies the `@nexkitjs/core` header preset and removes `X-Powered-By`. Options:
[Security → Secure headers](/docs/security/#secure-headers).

### `requestSizeLimit({ maxBytes })`

Rejects requests whose `Content-Length` exceeds the limit with `413` before any body is
read. `maxBytes` accepts numbers or strings like `"512kb"`. Keep `express.json({ limit })`
too — it covers chunked bodies without a declared length.

### `validateRequest({ body?, query?, params?, headers? })`

Validates request parts with any Standard Schema (Zod ≥ 3.24, Valibot, ArkType…). On
failure responds `422` via the error handler. Parsed values are stored in `req.validated`;
read them with `getValidated<Body, Query, Params, Headers>(req)`. Raw `req.body` etc. are
left untouched (Express 5 makes `req.query` a getter, so it cannot be reassigned).

### `healthRoutes(registry, options?)`

Mounts `GET /health/live` and `GET /health/ready` (configurable `livenessPath`,
`readinessPath`, `noCache`). Responds `200` or `503` with the JSON report.

### `rateLimit(options)`

```ts
rateLimit({
  limiter,                                // RateLimiter (required)
  keyGenerator: (req) => req.ip ?? "",   // default: req.ip
  cost: 1,                                // number or (req) => number
  skip: (req) => false,
  headers: true,                          // emit RateLimit-* headers
  style: "standard",                      // "standard" | "legacy" | "both"
  onLimit: (req, res, next) => …,         // custom 429 handling (default: next(TooManyRequestsError))
  onStoreError: "allow",                  // "allow" (fail-open) | "deny"
});
```

### `notFoundHandler()`

Forwards a `NotFoundError` for unmatched routes so 404s share the error envelope and are
logged consistently.

### `errorHandler(options)`

```ts
errorHandler({
  logger,                         // logs 5xx as error, 4xx as warn (when logClientErrors)
  logClientErrors: true,
  includeRequestId: true,         // adds requestId to the body
  onError: (err, req, res) => {}, // metrics, Sentry…
  formatBody: (err, req) => ({ …custom shape… }),
  trustForeignStatus: true,       // honour status from body-parser & co.
});
```

Normalizes any error with `normalizeError`, applies `err.headers` (e.g. `Retry-After`),
sends `err.status` with the standard envelope, and if headers were already sent delegates to
Express's default handler. Mount it **last**.

### `asyncHandler(fn)`

Express 4 helper: `app.get("/x", asyncHandler(async (req, res) => { … }))`.

## Type augmentation

Importing `@nexkitjs/express` augments `express-serve-static-core`'s `Request` with
`id?: string`, `correlationId?: string` and `validated?`. Nothing else is modified.

## Testing

```ts
import request from "supertest"; // or fetch against app.listen(0)
import { createTestLogger } from "@nexkitjs/testing";

const logs = createTestLogger();
const app = buildApp({ logger: logs.logger });

const res = await request(app).get("/api/users/999");
expect(res.status).toBe(404);
expect(res.body.error.code).toBe("NOT_FOUND");
expect(res.headers["x-request-id"]).toMatch(/^[0-9a-f-]{36}$/); // UUID
expect(logs.find("request completed")?.status).toBe(404);
```

See the example app's tests for request-id propagation, validation, rate limiting and
secret-leak assertions.
